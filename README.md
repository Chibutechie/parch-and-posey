# SQL Project: Parch & Posey

A comprehensive SQL analysis project using the fictional paper company "Parch & Posey" dataset to demonstrate advanced querying capabilities and business intelligence insights.

## Project Objective

SQL is a fundamental skill in the data professional's toolkit, and mastering its application is crucial for extracting meaningful insights from data.

In this project, I leverage the Parch & Posey dataset to answer critical business questions through SQL queries. The goal is to showcase proficiency in:

- Complex query construction
- Data aggregation and analysis
- Joining tables
- Creating views
- Business problem-solving with SQL
- Query optimization techniques

## Project Structure

```
├── parch_and_posey/        # Project folder
├── parch_and_posey.sql     # Main database schema and setup

```

## Getting Started

1. Clone this repository
2. Load the `parch_and_posey.sql` file into your SQL environment
3. Explore the queries in the `parch_and_posey/` directory
4. Run and modify queries to gain insights
